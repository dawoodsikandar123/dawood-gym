# Dawood Gym Management System

A web-based gym management system built with HTML, PHP, and MySQL.

## Team Members
- Dawood Sikandar (Project Leader)
- Moiz Hussain
- Rayan Mahmood
- Ali Ahmed

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Server: XAMPP

## Features
- Admin Login
- Member Management
- Trainer Management
- Activity Management
- Attendance Tracking
- Payment Tracking

## How to Run
1. Install XAMPP
2. Copy project to htdocs/dawood-gym/
3. Import dawood_gym.sql in phpMyAdmin
4. Open: localhost/dawood-gym/login.html
